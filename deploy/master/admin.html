Make a world

    The panel installs and builds it: several minutes before it is online.

    Add a world that already runs one you host elsewhere, by its address

    A world without https is played on this site (/play?world=...), which carries the game connection to it. So that it sees who is really connecting, set its egg's "Master address" to this site and its "Master proxy key" to this key, then restart it.

    A fresh start every account, on every world

    Resets every world to new: all accounts, characters, banks and bots, and what players built up (clans, scoreboards). Bans and mutes stay. Each world sets its saves aside in a backup folder on its own server as it restarts; nothing is deleted, but putting them back is done by hand.
